1. Аннотация и сведения о проверке

Отчёт фиксирует результаты реализации и проверки ревизии v0.01.01 веб-инструмента «Конструктор СКИБ» по техническому заданию версии 0.01.01. Ревизия развивает v0 без изменения форматов файлов и модели данных: добавлены модель доверия доменов и целостности потоков (3.5 ТЗ — классы НДБ/ДДБ/ДДБПЦД, автоматическая раскраска доменов и стрелок, рамка периметра), коэффициенты доверия в формуле стоимости (3.3, 7.1 — НДБ ×0.1, ДДБ ×5, ДДБПЦД ×10), внешние (смежные) системы как отдельный тип объекта (3.1, 6.1, 6.3, 6.4 — без стоимости, без функций, доверенность по признаку trusted), перестановка панелей интерфейса с выносом целей на левую панель и расчёта системы — под инспектор с укрупнённым шрифтом (5.1), переключение темы светлая/тёмная с тёмной по умолчанию (5.1), два демонстрационных примера — «Автономный коммунальный робот» и «Безэкипажное судно-доставщик» (14.4, Приложения А–В), обновлённые наборы тестов (T-T-01…T-T-10, обновлённые T-C-01…T-C-12, сценарии Э-01…Э-09 с Э-02b и Э-06b) и изменения развёртывания (базовый образ node:22-alpine, переменная PORT для dev/preview).

Вся функциональность v0 сохранена и перепроверена; раскраска доверия пересчитывается автоматически после каждой операции и при загрузке файлов (Ф-18), стоимость и покрытие считаются на одной модели проекта.
